如果看不到扩展名，先在资源管理器里打开「文件扩展名」，确保最终文件名是 Aaim.z01，而不是 Aaim.z01.zip。

2
改名、解压

Aaim2.zip → Aaim.z01；解压 Aaim.zip，得到 aaim-1.0.0-x64.msi。

3
安装、填 Key

双击安装包，启动 Aaim，在设置里填接口地址和 API Key，开始用。按当前用户安装，不需要管理员权限。

建议用 7-Zip 或 WinRAR 解压；解压前，两个文件必须放在同一个文件夹。
