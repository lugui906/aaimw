Built-in Apps

四个开箱即用的 AI 应用

都在同一个界面里，切换即用。它们不只是问答——需要动手的时候，真的会动手。

AI 助手

通用对话：搜索、答疑、写作、分析文档，把一个任务整段交给它。

  • 写周报 / 编辑文档 / 编码 / 搜资料 快捷指令
  • 可上传或拖入任意文件让它读取

桌面控制

用一句话让 AI 操作你的电脑：开应用、点按钮、填表单、截图排障。

  • Windows 用 pyautogui 驱动鼠标键盘
  • 先看当前窗口，再决定怎么动手

自动化

把口头描述变成可执行的脚本与规则，让 AI 帮你把流程跑起来。

  • 对话生成脚本 / 规则并执行
  • 适合批量、重复、定时类工作

日程

用自然语言安排当天任务，条件一到自动执行，不用自己盯时间。

  • 每天定点 / Cron / 打开某应用时触发
  • 到点由 AI 自动执行
Features

它都能帮你做什么

围绕「让 AI 真正懂你、替你做」设计的一整套能力，Windows 上该有的都有。

截图

截图提问 · 认字

一键截全屏，用系统自带 Windows.Media.Ocr 识别文字（语言包缺失时回退 tesseract），直接随问题发给 AI；也能粘贴剪贴板里的图片。

读屏

读取窗口上下文

先把当前前台窗口与最近活动交给 AI，再回答或动手，少解释很多。

上传任意文件

文档、表格、代码、日志都行。AI 拿到文件后自行读取、分析、总结。

一键朗读

任意一条回复点一下就用 Windows SAPI 读出来，可随时停止，适合边做事边听。

记忆

AI 记忆

随包 opencode 记忆插件提供 remember / forget / memories；记住你的习惯、职业、常用软件，可每天 / 每周 / 每月 / 每季自动更新。

活动记录 · 附加上下文

用 Win32 采集前台窗口与最近文件，提问时按需带上最近 5 分钟到一整天的活动，让回答更贴你的场景。

模型随你挑

自动检测可用模型并记住你的选择；deepseek、openai、anthropic、google、groq、xai 等厂商一键接入。

本机保存

API Key 管理

在设置里添加、查看（脱敏）、删除各厂商 Key，只保存在本机，随请求才发出。

多会话管理

新建、切换、连续追问，一个话题一个会话，随时回到之前的上下文继续。

历史搜索 · 收藏

搜索所有历史对话里的消息，把重要的收藏起来；还能多选批量复制或删除。

系统 AI 应用一览

把系统里其它的 AI 应用集中列出，在 ChinAI3 里直接打开，不用到处找。

更像人的对话

简洁气泡 + 清爽界面常驻桌面，随时呼出，不问也能待命。

Install

两步装进你的桌面

面向 Windows 10 / 11（64 位），按当前用户安装，不需要管理员权限。

1

前往中国移动云盘下载 chinai3-1.0.0-x64.msi，双击按提示完成安装（免管理员）。

2

从开始菜单或桌面快捷方式启动，在「设置 → 模型 / API Key」里填好 Key，就能开始对话。

也可以下载免安装包 chinai3-win-1.0.0.zip 解压后直接运行；或跑 install.ps1 安装到当前用户目录（同一个云盘分享）。

msiexec /i chinai3-1.0.0-x64.msi /qn   :: 静默安装
msiexec /x chinai3-1.0.0-x64.msi /qn   :: 静默卸载

Win10 如果缺少 Edge WebView2 Runtime，请先安装系统组件；没有它时会回退到默认浏览器。
